# Инициализация Memory Bank для проекта "Крестики-нолики"

## 🎯 Твоя задача

Ты — Cline. Прямо сейчас тебе нужно **создать структуру Memory Bank** для проекта
"Крестики-нолики", чтобы в будущих сессиях (после сброса контекста) ты мог
быстро войти в курс дела, не читая весь код заново.

Прочитай текущий проект, извлеки из него всю важную информацию и разложи её
по 6 файлам в папке `memory-bank/`. Затем создай правила `.clinerules/` и
файл `.clineignore`.

**Действуй пошагово. После каждого шага показывай результат и жди подтверждения.**

Это инструкция, которая **автоматически загружается в каждый новый чат Cline**.
Создай файл со следующим содержимым:

````markdown
# Cline Memory Bank — правила работы с проектом

Я — Cline, эксперт-разработчик. Моя память полностью сбрасывается между
сессиями. Это не ограничение — это причина вести идеальную документацию.

## 🔴 ОБЯЗАТЕЛЬНО в начале КАЖДОЙ задачи

Прежде чем что-либо делать, я ОБЯЗАН прочитать ВСЕ файлы из папки `memory-bank/`:

1. `memory-bank/projectbrief.md`
2. `memory-bank/productContext.md`
3. `memory-bank/activeContext.md`
4. `memory-bank/systemPatterns.md`
5. `memory-bank/techContext.md`
6. `memory-bank/progress.md`

Это не опционально. Без чтения этих файлов я не понимаю проект.

## 📐 Как я работаю

1. Прочитал Memory Bank → понял контекст
2. Прежде чем менять код — уточнил у пользователя, если что-то неясно
3. Делаю точечные правки, не переписываю проект целиком
4. Если узнал что-то новое о проекте — обновляю соответствующий файл Memory Bank
5. После значимых изменений — обновляю `activeContext.md` и `progress.md`

## 🔄 Команды, которые я понимаю

| Команда пользователя | Что я делаю |
|---|---|
| `update memory bank` | Перечитываю проект и обновляю все файлы Memory Bank |
| `follow your custom instructions` | Читаю Memory Bank и жду задачу |
| `initialize memory bank` | Создаю структуру Memory Bank с нуля |

## 🚫 Чего НЕ делать

- Не читать `node_modules/`, `*.sqlite`, `package-lock.json` — они в `.clineignore`
- Не переписывать рабочий код без причины
- Не молчать, если требования противоречат текущему коду — сообщить
- Не оставлять устаревшую информацию в Memory Bank

## 📏 Размер файлов

Memory Bank должен оставаться компактным:
- `activeContext.md` ≤ 50 строк
- `progress.md` ≤ 80 строк
- Остальные ≤ 80 строк

Если файл разрастается — сжимать, переносить детали в код/README.
