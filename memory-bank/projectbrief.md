# Project Brief: Крестики-нолики

## Что это

Веб-игра «Крестики-нолики» 3×3 с сохранением результатов партий в SQLite.
Игрок играет за X, компьютер — за O. Результат каждой партии автоматически
сохраняется в базу и отображается в истории на главном экране.

Проект создан по ТЗ из `promt.md` методологией **Harness** — последовательно
отработали 5 ролей: Architect → Developer → Tester → Reviewer → Documenter.

## Цели

- Полноценная игра в браузере с отзывчивым интерфейсом
- Хранение результатов партий между перезапусками сервера
- Минимум зависимостей: без фронтенд-фреймворков и внешних сервисов
- Запуск одной командой `npm install && npm start`
- Автоматические тесты без браузера

## Границы (что НЕ входит в проект)

- ❌ Онлайн-мультиплеер и WebSocket-сервер
- ❌ Авторизация, аккаунты, сессии
- ❌ Рейтинг и сложный ИИ (минимакс)
- ❌ Поля других размеров (4×4, 5×5) — логика завязана на 3×3
- ❌ Фронтенд-фреймворки, сборщики, CDN

## Ключевые фичи

- ✅ Два экрана: меню и игровое поле (одна страница, переключение состояний)
- ✅ Два режима: против компьютера и **«2 игрока»** за одним устройством
- ✅ ИИ компьютера: выиграть → заблокировать → центр → угол → любая клетка
- ✅ Определение победы (4 типа линий) и ничьей
- ✅ Индикатор текущего хода, подсветка выигрышной комбинации
- ✅ Автосохранение результата после каждой партии
- ✅ История последних 10 игр + кнопка «Очистить историю»
- ✅ Тёмная тема, адаптивность под мобильные
- ✅ Тройная валидация имён (до двух) → клиент → сервер → `CHECK` в БД
- ✅ Миграция БД v1→v2 без потери данных
