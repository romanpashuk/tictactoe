## Найденные и исправленные баги

Все три найдены на этапе Developer, четвёртый — позже, при ручной проверке.
Все **уже исправлены**:

| Серьёзность | Суть |
|---|---|
| **BLOCKER** | `currentTurn` не возвращался к `'X'` после хода компьютера — партия упиралась в один ход |
| **MAJOR** | `isThinking` никогда не выставлялся в `true` — поле не блокировалось на время хода ИИ |
| **MAJOR** | Потеряны 2 закрывающие скобки: 22 из 24 функций клиента стали вложенными и не экспортировались |
| **BLOCKER** | **Незакрытая скобка в `style.css`**: правило `.table-wrap` «съело» `.board` и `.cell` — поле 3×3 не отображалось вообще (виден был только текст) |

⚠️ **Важный урок про B3:** `node --check` (проверка синтаксиса из ТЗ) проходил
**успешно** при сломанном коде. Нашёл только через `vm`-прогон, где функции не
попадают в `globalThis`. Вывод: синтаксическая проверка недостаточна, нужны
тесты на поведение.

⚠️ **Урок про CSS-баг:** 85 проверок его не поймали — все читали код и звали
функции, но никто не проверял, что CSS **применится**. Незакрытая скобка
превращает последующие правила во вложенные (`.table-wrap .board`), а такого
элемента в DOM нет. Добавлен `css-check.js`: баланс скобок + проверка, что
ключевые селекторы на верхнем уровне. **Для CSS аналога `node --check` нет.**

⚠️ **Урок про тесты:** `Node fetch` не понимает относительные пути (`/api/games`),
из-за чего POST в e2e-тесте улетал в никуда, а тест это **маскировал** — падал
лишь на проверке «запись появилась в БД». Признак: тест зелёный на 17 из 18
проверок.

## Важные заметки для следующей сессии

1. 🔴 **Не рассчитывай на автозагрузку правил.** Проверено фактически
   05.10.2026: `.clinerules/memory-bank.md` в контекст сессии **не попал** —
   я узнал о Memory Bank только когда пользователь спросил. Файлы
   `memory-bank/*.md` и `README.md` тоже не загружаются сами.
   **Действие:** первым делом прочитай `memory-bank/activeContext.md`,
   затем остальные 5 файлов. Инструкция есть в начале `README.md`.
2. **Memory Bank может отставать от кода** — если видишь расхождение, верь коду
   и обнови нужный файл.
3. **После любых правок запусти `npm run test:all`** — сейчас 5 наборов,
   93 проверки.
4. **Не оставляй фоновые процессы `node server.js`** — они держат порт 3000
   и ломают следующий `npm start` (`EADDRINUSE`). Проверка: `lsof -nP -iTCP:3000 -sTCP:LISTEN`.
5. **`database.sqlite` в `.gitignore`** — БД создаётся автоматически.
6. **`npm run test:all` требует запущенного сервера** (из-за `e2e-game.js`).
   Первые четыре набора работают без него.
7. **Файл `memory-bank-init.md`** — ТЗ на создание самого Memory Bank,
   выполнено. Не путать с `promt.md` (ТЗ на саму игру).
8. **Не переписывать код целиком** при мелких правках — это уже привело
   к двум багам с потерей скобок (в `script.js` и в `style.css`).
9. **Перед правкой HTML/CSS проверяй баланс скобок** — именно так были
   найдены оба бага со скобками.
